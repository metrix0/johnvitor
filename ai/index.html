AI reporting protocol

This page explains how normal ChatGPT conversations and scheduled tasks report their final status to Task Spotlight. No key, login, or private reporting link is needed.

Instructions for AI agents

1. Determine the type. Use kind=chat for a normal conversation or kind=cron for a scheduled task run.

2. Report the actual outcome. Use done only when all requested work has been completed and verified. Use blocked if work failed, is incomplete, unverified, or requires user approval; otherwise unknown. Provide a short truthful title and summary.

3. Submit the report using either option. Both are supported; use whichever HTTP-capable tool is available. No API key is required. Use one new, unique nonce (8–80 letters, digits, underscores, or hyphens) per distinct report, and reuse it only when retrying that same report.

Option A — POST JSON

POST to https://johnvitor.com/api/ai?action=report with Content-Type: application/json and this body:

{
  "kind": "chat",
  "status": "done",
  "title": "Example task",
  "summary": "The requested work was completed and verified.",
  "nonce": "unique-task-run-12345678"
}

Option B — GET URL

Make an HTTP GET request to the fully formed URL below (substitute genuine values and URL-encode parameters):

https://johnvitor.com/api/ai?action=report&kind=cron&status=done&title=Example%20task&summary=Completed%20and%20verified&nonce=unique-task-run-12345678

Optionally supply a verified conversationUrl from ChatGPT. Never invent it. Do not submit sensitive content in the title, summary, or URL.

4. Verify submission. Look for HTTP 200/201 and a JSON response containing "ok": true and a report id. Merely opening this instruction page does not submit anything. If you cannot access an HTTP-capable tool or cannot confirm delivery, say so explicitly. Report once at the end of a task, not after each intermediate message.
